# 造印机：开发与验收（YOU-191 / YOU-198 / YOU-200）

入口是 `web/maker.html`。界面按何流东提供的 [EngineerAgent](https://engineeragent.zichengyu.com/) 参考采用侧栏、灰白工作区、橙色强调、步骤条与浅色/深色主题；印章、盲文和拓印仍来自万物印自己的几何与模型。

## 本地运行

网页：

```bash
cd web
npm ci
npm run dev -- --host 127.0.0.1 --port 5199 --strictPort
```

打开 `http://127.0.0.1:5199/maker.html`。只体验现有印章时不需要生成后端。

在线生成另开终端启动 YOU-197 后端，按 [造印机后端.md](造印机后端.md) 准备 Python、liblouis 和本地密钥。当前这台 Windows 电脑可在仓库根目录运行：

```powershell
.\pipeline\out\start_seals.ps1 --port 8000
```

该辅助脚本位于忽略目录，仅供当前电脑使用；其他电脑使用 `pipeline/scripts/serve_seals.py`。Vite 将 `/api` 转发到本机 8000。Lux3D key 始终由后端读取，前端不读取 `.env`，也不接收 key。

## 三条路径

### 文字

在“文字造印”中输入一句话，名字会自动从描述提取，也可以修改。故事与真实尺寸可补充；未知尺寸明确写为“真实尺寸待补充”，不会猜测数值。

若描述精确命中已有物件，直接展示并标注“已备好的印”，不会发起付费生成。未命中时提交在线任务，显示排队、准备、生成和下载状态，以及已等待时间。预计时间只作参考，不展示虚构的精确进度百分比。

### 照片

选择 PNG/JPEG/WebP 照片（不超过 8 MiB），填印上的名字，再提交。照片始终走真实的图生接口，不会仅因名字与现有印相同就忽略上传的照片。离线时会说明照片需要联网，并提供三枚现有印的体验入口。

### 已备好的印

点击“大象 / 蓝鲸 / 甬钟”，或在文字框中输入其名字及别名，可以直接体验：

1. **认形状**：拖动查看，或用旋转、缩放按钮操作。
2. **翻面读名字**：看到轮廓浮雕和盲文；完成后可拓印。
3. **拓出一页书**：播放交互动画，展示完成的一页。
4. **收藏**：存入当前浏览器的“我的印集”。在线新生成的印会自动入集；合影页支持这些条目。

动画由共享的 `seal-animation.ts` 驱动，与原三联图、合影和动画页共用 `seal-geo.ts`。减少动态效果偏好开启时，动作直接到达对应状态。浏览器回归仅截图，不录制视频。

## 离线准备与缓存清单

“准备离线体验”需要先联网，会保存页面、样式、脚本依赖，以及大象、蓝鲸、甬钟三枚 GLB。完成后可真正断网并刷新页面，再走完整的翻面、拓印和收藏流程。Service Worker 仅缓存同源静态内容，排除 `/api/`；生成响应和凭据不进入缓存。

`?offline=1`、工作台“离线体验”卡片或侧栏“仅使用已备好的印”都会关闭在线生成与任务查询。浏览器检测到断网也会暂停查询。未命中的物件会给出说明和现有印的选择，不会伪装成在线生成。已有在线任务保留原记录，联网并退出离线模式后继续查询。

首版复用现有 8 枚 Lux3D 资产，无需批量新生成。别名表在 `web/public/seal-cache.json`：

| 缓存物件 | 可输入的名称示例 | 默认离线包 |
|---|---|---|
| 大象 | 大象、非洲象、象、elephant | 是 |
| 蓝鲸 | 蓝鲸、鲸鱼、blue whale | 是 |
| 甬钟 | 甬钟、编钟、青铜钟 | 是 |
| 霸王龙 | 霸王龙、恐龙、暴龙、t-rex | 按访问缓存 |
| 大白鲨 | 大白鲨、白鲨、鲨鱼、shark | 按访问缓存 |
| 蚂蚁 | 蚂蚁、ant | 按访问缓存 |
| 土星 | 土星、saturn | 按访问缓存 |
| 火山 | 火山、volcano | 按访问缓存 |

匹配会去掉标点、空格、“我想摸摸”等前缀及量词；只匹配完整名称。“蓝鲸和土星”不会被误当成单个物件。`generated.json` 和本地收藏中的有效条目也可加入清单；精选 `seals.json` 不改写。

离线保存依赖支持 Service Worker 的浏览器，以及 HTTPS 或 localhost。换浏览器、清理网站数据或浏览器回收存储后，需要重新准备。生产静态服务器必须提供打包后的 JS/CSS 和模型文件；新版本修改缓存格式时更新 `maker-sw.js` 的缓存版本。

## 刷新、断线与重复请求

提交前用 IndexedDB 保存请求及 Idempotency-Key，照片按 Blob 保存；得到后端任务号后追加保存。若 POST 的响应丢失，恢复时仍用同一 key 和同一内容；已知任务号则只查询，不再次创建。

网络失败会保留请求并显示“继续这次请求”或“继续查询这枚印”。在任务得到明确终态前，输入表单保持锁定，防止把重复点击变成另一个付费任务；此时仍可体验三枚已备好的印。明确的参数拒绝或失败终态会恢复输入。

收藏存于浏览器本地，不承诺跨设备同步。图像、任务数据库和运行生成的模型均由 `.gitignore` 排除。

## 验证

```bash
cd web
npm run test:maker   # Node 24：名称匹配、清单校验、离线包资产
npm run build       # TypeScript 与生产打包
npm run check:maker # 已启动网页时运行真实浏览器回归
```

浏览器脚本使用仓库原有 `playwright-core`，Windows 默认使用本机 Edge，可用 `CHROME_PATH` 指定其他浏览器。`MAKER_BASE_URL` 可指定生产预览地址。脚本会检查真实断网刷新、三枚印的完整交互、收藏合影、请求响应丢失后的重试、照片与任务号刷新恢复、手机布局、主题和键盘操作。生成 API 使用测试桩，不会消耗 Lux3D 积分。

浏览器检查报告与截图写入忽略目录 `output/playwright/`。新增真实生成的任务号、积分和结果另记 Linear / PR。VoiceOver 的实际语音播报需在支持它的设备上复核；本轮可验证可访问名称、状态区域更新和键盘流程。

本轮按用户要求先完成开发，不执行视频录制；YOU-191 的录屏验收项保留待办。
