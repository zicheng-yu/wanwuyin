# 造印机后端（YOU-197）

Python 标准库 HTTP 服务，复用 `wwys/lux3d.py`。任务与积分账本保存在 SQLite，模型发布到网页目录；精选的 `seals.json` 不会被修改。

## 启动

先按 README 安装 Python 3.12、`pipeline/requirements.txt` 与 liblouis。`lou_translate` 必须能在 PATH 找到，并带 `unicode.dis`、`zhcn-cbs.ctb` 表。Windows 可使用 [liblouis 官方 Windows 构建](https://liblouis.io/downloads/)，将解压后的 `bin` 目录加入当前终端 PATH；必要时将 `LOUIS_TABLEPATH` 指向其 `share/liblouis/tables`。Windows 的 Python 位于 `.venv\Scripts\python.exe`，下列命令以 macOS/Linux 为例。

密钥从环境变量 `LUX3D_CN_API_KEY` 读取；未设置时依次读取 `pipeline/.env`、仓库根目录 `.env`。两处 `.env` 都被 git 忽略。不要把密钥放到 `VITE_*` 变量。

```bash
cd pipeline
.venv/bin/python scripts/serve_seals.py --port 8000 --daily-budget 100
```

另开终端启动网页：`cd web && npm ci && npx vite --port 5199`。Vite 已代理 `/api` 到 `127.0.0.1:8000`，前端直接请求相对地址 `/api/seals`。服务启动时会检查盲文转换依赖，避免生成成功后才发现缺少工具。

默认只监听本机。需要绑定 `0.0.0.0` 时必须在服务进程环境设置 `SEAL_API_TOKEN`，客户端使用 `Authorization: Bearer …`；浏览器调用应通过有访问控制的同源反向代理，不要把共享服务 token 编译进公开前端。可重复传 `--origin https://演示域名` 配置允许的浏览器来源，未传时允许本地 5199/5173 端口。响应不会包含 Lux3D key、上游任务响应或临时下载地址。

## 接口约定

### `POST /api/seals`

文字输入，`Content-Type: application/json`：

```json
{
  "label": "长颈鹿",
  "why": "太高",
  "real": "高约五米",
  "prompt": "一只站立的长颈鹿，写实风格，完整全身，白色背景"
}
```

照片输入推荐使用 `FormData`：

```ts
const form = new FormData();
form.set("label", "甬钟");
form.set("why", "太珍贵");
form.set("real", "高约四十五厘米");
form.set("image", photoFile);
const response = await fetch("/api/seals", {
  method: "POST",
  headers: { "Idempotency-Key": crypto.randomUUID() },
  body: form,
});
const job = await response.json();
```

同一点击的网络重试要复用同一个 `Idempotency-Key`。首次返回 **202**；相同 key 与相同内容返回原任务 **200**，不会重复生成；相同 key 换了内容返回 **409**。浏览器重载后若要继续重试，应保存该 key 与任务号。

JSON 也支持 `"image": "data:image/png;base64,…"` 或 `"image": {"base64": "…"}`。照片最大 **8 MiB**，接受 PNG/JPEG/WebP；不接受远程图片 URL 或本地文件路径。客户端文件名不用于服务器路径。`prompt` 与 `image` 只能提供一种；`label`、`why`、`real` 都必填。名字中的数字请写成汉字。标签不接受 HTML 或控制字符。

响应结构（字段示例）：

```json
{
  "id": "8ba46fe07d054d899bb4e6924db4c841",
  "name": "seal_8ba46fe07d054d899bb4e6924db4c841",
  "status": "queued",
  "createdAt": "2026-11-11T10:00:00+00:00",
  "updatedAt": "2026-11-11T10:00:00+00:00",
  "elapsedSeconds": 0,
  "estimatedSeconds": 240,
  "queuePosition": 1,
  "quoteCredits": null,
  "seal": null,
  "error": null
}
```

### `GET /api/seals/<id>`

返回同一结构。建议每 2–5 秒轮询；`completed`、`failed` 为终态。状态依次为 `queued`、`quoting`、`generating`、`downloading`、`completed` 或 `failed`。`estimatedSeconds` 是既有经验值（文生 240 秒、图生 60 秒），不代表上游保证。

完成后的 `seal` 与现有 `seals.json` 条目兼容，包含 `name/label/cells/why/real/glb/yaw`，可交给印章几何和动画函数。失败时 `error` 包含稳定的 `code` 与中文 `message`，前端不应显示原始上游异常。

### 其他读取接口

| 地址 | 响应 |
|---|---|
| `GET /api/health` | `{"status":"ok"}` |
| `GET /api/seals` | `{"seals":[已完成条目]}` |
| `GET /generated.json` | 已完成条目的数组 |
| `GET /objects/seal_<id>/model.glb` | 已完成模型；其他路径不提供文件服务 |

开发时 Vite 直接提供 `web/public/generated.json` 和新模型。生产部署应将 `/generated.json` 和 `/objects/seal_*/model.glb` 转发到后端，或让静态服务器直接提供持续更新的发布目录；仅复制构建时的 `dist` 无法提供之后生成的模型。造印工作台与展示页已合并精选、生成清单和本地收藏；`seal.html?view=set&collection=1` 只展示当前浏览器收藏的印。

## 任务、积分与恢复

- 最多 **5 个 worker**；第 6 个及后续请求留在 SQLite 队列，默认最多接受 100 个未完成任务。上游因其他客户端占用额度返回并发限制时，本地任务重新排队，释放本次积分预留。
- 每次先报价，再检查单次上限（文生 **15**、图生 **3**）与每日总额。默认每日 **100** 积分，可用 `--daily-budget` 调整。预算按北京时间自然日记账，通过 SQLite 事务在多个 worker 间原子预留，重启仍有效。
- 积分账本保守计算：创建成功、后续失败或创建结果不明都保留预留额，不假设上游自动退款。它只统计本状态目录发起的任务，不统计别处直接使用同一 key 的消费。
- `create` 前先落盘 `creating` 标记；返回上游任务号后立即保存。重启后，已知任务号的任务继续轮询/下载，排队任务继续执行，报价中的任务重新报价。
- 上游创建接口未提供可用的幂等保证。若进程在“上游已接收、任务号尚未落盘”的窗口退出，或创建请求超时，记录 **`CREATE_UNCERTAIN`**，保留预算并停止自动创建。管理员必须先核对上游，避免重复扣费。
- 完成后立即下载 GLB，限制 **128 MiB**，校验 GLB 头与长度；先写 `.part` 再原子替换。输出链接不会暴露给前端。随后计算国家通用盲文和朝向，提交结果并原子更新 `generated.json`。
- 下载或元数据处理失败记录 **`PROCESSING_FAILED`**。停止当前后端后可运行 `serve_seals.py --retry-processing <id>`，或用下述 CLI 恢复。复用原上游任务号；若本地 GLB 已存在则不重复下载，也不重复生成。
- 同一状态目录只允许一个 worker 池，防止开两个服务导致并发翻倍。优雅退出会等正在进行的网络调用返回，再释放锁；强制退出后由 SQLite 恢复。

默认状态目录：`pipeline/out/seal-service/`，含 `jobs.sqlite3`、上传图片和实例锁，**不可放到公开目录**。运行生成的清单及 `objects/seal_*` 已被 git 忽略；部署或备份时按需带上它们。精选 8 枚模型不受影响。

## 单命令生成

与 HTTP 服务共用 worker、预算与元数据逻辑；同一状态目录下不要同时启动服务和 CLI。

```bash
cd pipeline
.venv/bin/python scripts/add_seal.py --label 长颈鹿 --why 太高 --real 高约五米 \
  --prompt "一只站立的长颈鹿，写实风格，完整全身，白色背景"
.venv/bin/python scripts/add_seal.py --label 甬钟 --why 太珍贵 --real 高约四十五厘米 --image ref.jpg
.venv/bin/python scripts/add_seal.py --resume <任务号>
```

CLI 输出公共任务状态和最终条目。`--resume` 复用任务号；处理失败时会重新处理原模型，创建结果不明时不会自动重建。

仓库根目录执行以下命令，不需要 key、网络或额外 Python 包：

```bash
python -m unittest discover -s pipeline/tests -v
```

测试包含 HTTP 文字/照片上传、GLB 下载、同 key 并发重试、6 任务限流、预算竞争与重启保留、轮询断线、创建结果不明、处理恢复、凭据脱敏及文件路径隔离。真实 Lux3D 验收及实际扣费另记在 YOU-197 / PR 中。
